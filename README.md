# Турă — scroll-world

Иммерсивный лендинг по чувашской сказке-происхождению о **Турă**: скролл управляет камерой через три сцены, ниже — полный текст сказки.

## Локальный запуск

```bash
cd tura-repo
python3 -m http.server 9876
```

Открой [http://127.0.0.1:9876/](http://127.0.0.1:9876/).

> Если в macOS включено «Уменьшение движения», сайт всё равно грузит видео (`forceMotion`).

## Структура

```
tura-repo/
├── index.html          # scroll-world + текст сказки
├── scrub-engine.js     # движок скролл-камеры
├── story.md            # сказка в markdown
├── assets/
│   ├── *.webp          # постеры сцен
│   └── vid/*.mp4       # dive + connector клипы
└── README.md
```

## Сцены

1. **Сотворение** — мир Турă и деревня у озера  
2. **Раздор** — Усалы / Шуйтаны и явление над водой  
3. **Чӳклеме** — молитва и живительный дождь  

## Источник

Текст по мотивам традиционных верований чувашей; см. [Чувашскую энциклопедию](https://chuvenc.ru).

Видео-клипы сгенерированы через Higgsfield (Seedance 2.0 Mini) по референс-иллюстрациям.
